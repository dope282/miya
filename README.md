# MIYA Boutique — онлайн дэлгүүр

Эмэгтэй хувцасны дэлгүүр: каталог, сагс, захиалга, админ самбар, хүргэлтийн хамтрагч компанийн самбар.

## Vercel дээр байршуулах

1. Кодоо GitHub руу оруулна (`git add . && git commit && git push`).
2. Vercel → төсөл → **Storage** → **Create Database** → **Neon (Postgres)** → төсөлдөө холбоно.
   `DATABASE_URL` орчны хувьсагч автоматаар нэмэгдэнэ.
3. Vercel → төсөл → **Settings → Environment Variables** → `ADMIN_PASSWORD` нэртэй хувьсагч нэмж, админы нууц үгээ бичнэ.
4. **Deployments** → сүүлийн deployment → **Redeploy**.

Хүснэгтүүд болон жишээ бараа анхны хүсэлтээр автоматаар үүснэ.

| Хуудас | Хаяг |
|---|---|
| Дэлгүүр | `https://<таны-домэйн>/` |
| Админ | `https://<таны-домэйн>/admin` |
| Хүргэлтийн хамтрагч | Админ → «Хүргэлт» цэсээс холбоосыг хуулна |

Орчны хувьсагчид:

| Нэр | Тайлбар |
|---|---|
| `DATABASE_URL` | Postgres холболт (Neon холбоход автоматаар үүснэ) |
| `ADMIN_PASSWORD` | Админы нууц үг — **заавал** |
| `COURIER_KEY` | Хүргэлтийн холбоосын түлхүүр (заавал биш; өгөөгүй бол санд автоматаар үүснэ) |

## Компьютер дээр ажиллуулах

```bash
npm install
```

```bash
node server.js
```

`DATABASE_URL` байхгүй үед өгөгдөл `data/pg` хавтсанд (PGlite) хадгалагдаж, админы нууц үг `data/secrets.json`-д үүснэ.
Vercel-ийн жинхэнэ сантай ажиллах бол төслийн үндсэн хавтсанд `.env` файл үүсгэж `DATABASE_URL=...`, `ADMIN_PASSWORD=...` гэж бичнэ.

Өмнөх хувилбарын `data/miya.db` (SQLite) болон `data/uploads` байвал хоосон санг анх асаахад бараа, захиалга, зураг автоматаар хуулагдана.

## Тохиргоо — `config.js`

Утас, цагийн хуваарь, хүргэлтийн төлбөр, үнэгүй хүргэлтийн босго, **банкны данс**, дүүрэг/хорооны жагсаалт,
хүргэлтийн компанийн нэр болон API хаяг (`webhookUrl`). Өөрчилсний дараа GitHub руу push хийхэд Vercel шинэчилнэ.
Дээд баннерыг админ → «Баннер» цэсээс засна.

## Захиалгын урсгал

1. Үйлчлүүлэгч захиална → **Шинэ** (үлдэгдэл шууд хасагдана)
2. Админ төлбөр/захиалгыг баталгаажуулна → **Баталгаажсан**
3. Админ «Хүргэлтэнд өгөх» дарна → **Хүргэлтэнд гарсан** (хамтрагчийн самбарт гарч ирнэ; `webhookUrl` байвал JSON илгээнэ)
4. Хүргэгч «Хүргэсэн» гэж тэмдэглэнэ → **Хүргэгдсэн**. «Чадсангүй» гэвэл админд ⚠ тэмдэглэгээтэй харагдана.

Цуцлахад барааны үлдэгдэл буцаж нэмэгдэнэ.

## Бүтэц

- `public/` — дэлгүүр, админ, хүргэлтийн хуудсууд (Vercel шууд үйлчилнэ)
- `api/index.js` — Vercel-ийн функц; `lib/app.js` — API-ийн логик; `lib/db.js` — өгөгдлийн сан
- `server.js` — зөвхөн компьютер дээр ажиллуулахад
- Барааны зураг өгөгдлийн санд хадгалагдана (оруулахад 1600px хүртэл жижигрүүлнэ)
