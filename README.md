# MIYA Boutique — онлайн дэлгүүр

Эмэгтэй хувцасны дэлгүүр: каталог, сагс, захиалга, админ самбар, хүргэлтийн хамтрагч компанийн самбар.
Нэмэлт сан суулгах шаардлагагүй, зөвхөн Node.js 22.13+ хэрэгтэй.

## Ажиллуулах

```bash
node server.js
```

| Хуудас | Хаяг |
|---|---|
| Дэлгүүр | http://localhost:3000/ |
| Админ | http://localhost:3000/admin |
| Хүргэлтийн хамтрагч | Админ → «Хүргэлт» цэсээс холбоосыг хуулна |

Админы нууц үг болон хүргэлтийн түлхүүр анх ажиллуулахад `data/secrets.json` файлд автоматаар үүснэ.
`ADMIN_PASSWORD`, `COURIER_KEY`, `PORT` орчны хувьсагчаар солих боломжтой.

## Тохиргоо — `config.js`

Утас, цагийн хуваарь, хүргэлтийн төлбөр, үнэгүй хүргэлтийн босго, хямдралын туузны бичвэр,
**банкны данс**, дүүрэг/хорооны жагсаалт, хүргэлтийн компанийн нэр болон API хаяг (`webhookUrl`) энд байна.
Өөрчилсний дараа серверээ дахин асаана.

## Захиалгын урсгал

1. Үйлчлүүлэгч захиална → **Шинэ** (үлдэгдэл шууд хасагдана)
2. Админ төлбөр/захиалгыг баталгаажуулна → **Баталгаажсан**
3. Админ «Хүргэлтэнд өгөх» дарна → **Хүргэлтэнд гарсан** (хамтрагчийн самбарт гарч ирнэ; `webhookUrl` байвал JSON илгээнэ)
4. Хүргэгч «Хүргэсэн» гэж тэмдэглэнэ → **Хүргэгдсэн**. «Чадсангүй» гэвэл админд ⚠ тэмдэглэгээтэй харагдана.

Цуцлахад барааны үлдэгдэл буцаж нэмэгдэнэ.

## Өгөгдөл

`data/miya.db` (SQLite) болон `data/uploads/` (барааны зураг). Энэ хавтсыг тогтмол нөөцөлж аваарай.
